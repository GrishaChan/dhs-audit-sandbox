# CP21 — унификация интерфейса переключателей

Дата: 5 ноября 2026. Основа: CP20.

## 1. Проблема

На главном экране активная категория выделена мягкой полупрозрачной капсулой с тонкой рамкой («Библиотека / Кинотека / Плейлист»). В статистике и истории CP19/CP20 выделяли активный пункт иначе:

| | Главный экран (CP20) | Статистика / история (CP20) |
|---|---|---|
| Рамка | 1 px, 45–55 % непрозрачности | **2 px**, 100 % (`inset 0 0 0 2px`) |
| Заливка | ≈ 15 % цвета категории | **26–32 %** цвета (`color-mix`) |
| Текст | цвет категории | основной цвет текста |
| Скругление | полное (капсула) | 14 px внутри дорожки 18 px |
| Цвет категории | `#d6a66b` / `#e99380` / `#5bdba9` (рамка) | `--c-books` и т. п. (другие оттенки) |

## 2. Единая система

Основа — капсула главного экрана. В CSS введены общие переменные (`--sw-*`). Те же значения уже использует капсула главного экрана (рамка `#d6a66b`/`#e99380`/`#5bdba9`, заливка `rgba(…,.15–.16)`, текст в цвете категории):

| Свойство | Значение для всех активных переключателей |
|---|---|
| Рамка | 1 px, цвет категории, непрозрачность 55 % (светлая) / 45 % (тёмная) |
| Заливка | полупрозрачная, ≈ 15 % цвета категории |
| Текст | цвет категории: светлая — `#85591d` / `#ad4937` / `#146b4b`, тёмная — `#f1c78b` / `#ffa994` / `#7bf0bf` (те же, что у главных вкладок) |
| Тень | мягкая, общая переменная `--sw-shadow` |
| Скругление | полное (капсула): и кнопка, и дорожка сегмента |
| Нажатие | `scale(.985)`, 170 мс — как у главных вкладок |
| Переключение | смена заливки, рамки и цвета 150–200 мс |

Применение:
- **Статистика**, уровень 1 «Книги / Фильмы / Музыка»: каждая кнопка в своём цвете (золотистый / розовый / зелёный).
- **Статистика**, уровни 2 «Моя активность / Коллекция» и 3 «День / Месяц / Год / Всё время»: цвет текущей категории экрана.
- **История**, «Книги / Фильмы / Музыка»: каждая кнопка в своём цвете.
- **Настройки**, «Как в системе / Светлая / Тёмная» (переключатель того же назначения): цвет текущего каталога.
- **Главный экран**: его правила (`.tab-glider`) теперь читают те же переменные (`--sw-edge-mix`, `--sw-shadow`). Его вид не изменился (подтверждено сравнением вычисленных стилей).

Размеры, отступы, шрифты, дорожка сегментов и компоновка не менялись. Вложенные уровни сохраняют свои размеры.

Сознательное различие. Капсула главного экрана *скользит* между вкладками (так было и раньше), а сегменты меняют выделение плавной сменой цвета. Скользящий индикатор в каждом сегменте потребовал бы новой разметки и JS-логики для пяти групп; по заданию радикальные изменения нежелательны, поэтому он не вводился.

## 3. Измерения

Скриншоты (мобильный режим, 390 px, 2×) — `verification/shots/compare_dark.png`, `compare_light.png` (слева CP20, справа CP21).

Автоматическая проверка (регрессионный набор, 3 категории × 2 темы × 2 компоновки; ниже — мобильные значения):

| Показатель | CP20 | CP21 |
|---|---|---|
| Толщина рамки активного пункта (все уровни) | 2 px | **1 px** (как у главной капсулы) |
| Форма | скругление 14 px | **капсула** |
| Цвет текста активного = цвет текста активной главной вкладки | нет | **да** |
| Отличие фона активного от неактивных (расстояние RGB) | 32–103 | 23–39 (заливка стала мягче, как у капсулы) |
| Отличие цвета текста активного от неактивных (расстояние RGB) | 76–87 (основной цвет текста вместо приглушённого) | 79–116 (цвет категории) |
| Контраст текста активного пункта | 7,0–9,2 : 1 | **4,85–7,1 : 1** (минимум — «Фильмы», светлая тема) |
| Контраст текста неактивных | ≥ 5,87 : 1 | ≥ 5,87 : 1 (не изменялся) |

Различимость в CP21 обеспечивается сочетанием трёх признаков: цветной текст, тонкая цветная рамка, мягкая заливка, — как на главном экране. Контраст текста активного пункта ниже, чем в CP20 (цветной текст вместо почти белого/почти чёрного), но во всех случаях выше 4,5:1 (WCAG AA для обычного текста). Это сознательный компромисс ради единого стиля; значения совпадают с уже утверждёнными главными вкладками.

Сравнение вычисленных стилей CP20 → CP21 (все элементы, 20 состояний интерфейса: 2 темы × 2 компоновки × каталог/каталог/меню/статистика/история): визуально изменились **только 21 элемент в каждом состоянии** — 5 дорожек сегментов, 15 кнопок в них и `<html>` (только удалённый мёртвый переход). Карточки, главная капсула, иллюстрации, типографика и размеры совпадают.

## 4. Консолидация CSS

| Действие | Объём | Проверка |
|---|---|---|
| Удалены правила CP19/CP20 толстого выделения (`--section-accent`, `inset 2px`, 26–32 %) | 10 строк | заменены единой системой |
| Удалены 12 регистраций `@property --bg … --nav-bg` | нужны были только перекрытой анимации темы v6 | вычисленные визуальные свойства идентичны в 20 состояниях |
| Удалены перекрытые `html.theme-ready{transition:…}` (v6) и `transition:none!important` (v7) | 2 правила, 1 `!important` | то же |
| Удалены `#catalog{…}` | действовали только до запуска сценария | то же |
| Удалены `.tab[aria-selected=true]{…}` (базовое и его отмена с 2 `!important`) | 2 правила | то же |
| Правила главной капсулы переведены на общие переменные, дубль для тёмной темы удалён | 1 правило | то же |

Итог: CSS 53 364 → 51 975 символов; `!important` 61 → 58; `@property` 15 → 3 (оставлены используемые `--art-c1..3`). Пересчёт стилей при смене категории и темы до/после — без измеримой разницы (CP21_PERFORMANCE_REPORT, раздел 4). Поэтому это **улучшение поддерживаемости, а не производительности**.

Не трогались: остальные слои v3–v17 и CP07/CP08, где удаление меняет вычисленные свойства (например, переходы `.story-toggle`, `.nav`). Перечень — в аудите CP20 (D-03).
