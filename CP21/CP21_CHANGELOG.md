# CP21 UI/PERF — журнал изменений

Дата: 5 ноября 2026. Основа: CP20 (`Moi_kollektsii_FINAL.html`, SHA-256 `475b9ecc66a72d485988f641026dde0f3bd074f909d0849c459aaf2908d17afe`, проверена; неизменяемая копия — `verification/source/Moi_kollektsii_CP20_source.html`). Точный diff: `verification/CP21_DIFF.patch` (18 участков, +89 / −49 строк; только `<style>` и основной сценарий).

## Для пользователя

1. **Единый стиль переключателей.** Все активные переключатели статистики, истории и настроек оформлены как капсула «Библиотека / Кинотека / Плейлист»: тонкая рамка 1 px, мягкая полупрозрачная заливка, текст в цвете категории, полное скругление, одинаковая реакция на нажатие. Толстые контрастные рамки CP19/CP20 убраны. Цвета категорий — золотистый, розовый, зелёный.
2. **Свайпы статистики и истории больше не пропускаются.**
   - Срабатывают, если начать с переключателей, с графика, сразу после прокрутки, «дугой» большого пальца, медленным уверенным движением.
   - Два быстрых свайпа подряд дают два переключения.
   - Касание по-прежнему работает как нажатие; вертикальная прокрутка не мешает.
3. **Без пауз после перехода.** Подготовленная заранее категория становится содержимым без повторной отрисовки.
4. **Надёжность при открытии из файлового менеджера Android (`content://`).** Смена каталога не выбрасывает ошибку, если браузер запрещает менять адрес страницы.

## Изменения кода

| Участок | Изменение |
|---|---|
| CSS, конец `<style>` | Единая система переключателей: переменные `--sw-*` (рамка, заливка, текст по категориям; степень непрозрачности рамки и тень по теме), общее правило активного `.seg button`, нажатие `scale(.985)`. Удалены правила CP19 (`--section-accent`, `inset 2px`, 32 %) и CP20 (`inset 2px`, 26 %). |
| CSS `.seg`, `.seg button` | Скругление 18/14 px → капсула (999px). Базовое активное правило (фон `--panel`) удалено. |
| CSS `.tab-glider` (v13) | Читает общие `--sw-edge-mix` и `--sw-shadow`; дубль для тёмной темы удалён (вид не изменился). |
| CSS, мёртвые правила | Удалены 12 `@property` (`--bg … --nav-bg`), перекрытая анимация `html.theme-ready` и её отмена, `#catalog{…}` ×2, базовое `.tab[aria-selected=true]` и его отмена. −3 `!important`. |
| `renderStats` | Разделён на `renderStatsControls()` (переключатели, период, цвет экрана) и отрисовку содержимого. |
| `renderHistory` | Наблюдатель подгрузки вынесен в `observeHistory()`. |
| `adoptSheetGhost()` (новая) | Принятие подготовленного слоя как содержимого после завершённого свайпа: история — с корректными `historyShown`, `historyLastDay`, подгрузкой. |
| `finishSheetMotion` | Принятие слоя вместо `renderStats()`/`renderHistory()`; запоминание направления последнего свайпа. |
| `historyPreviewHTML(k, rows)` | Слой истории — только видимые строки (24–80). |
| `scheduleSheetGhosts` | Учёт бюджета кадра простоя (≥ 12 мс); при движении — откладывание, а не отмена; первой готовится категория в направлении последнего свайпа. |
| Обработчики `touchstart/touchmove/touchend` экранов | Исключаются только элементы ввода. Направление определяется после 12 px по преобладающей оси, вертикаль — по фактической прокрутке (а не по `cancelable`). `preventDefault` только для кэнселабельных событий. Порог медленного перетаскивания — треть ширины. «Протяжка» на следующую категорию. |
| `endMotion` (каталог) | `history.replaceState` в `try/catch`. |
