# CP20 — технический аудит «Мои коллекции»

Дата: 4–5 ноября 2026. Объект: CP19 UI-FIX, единый автономный HTML 2 506 270 байт, SHA-256 `146bf3d7bc20f6187be1eb1bfecbaa1e8c6be81d6b57ae859056f78ec03a4efd` (совпала с `CP19_SHA256SUMS.txt` до начала работ; неизменяемая копия сохранена как `orig/Moi_kollektsii_CP19.html`).

Аудит выполнен по полному исходному тексту: CSS (строки 10–524), разметка (525–652), четыре JSON-блока данных (653–656), сценарий (657–1873, ≈150 КБ, из них 55 КБ — встроенные иллюстрации). Каждая найденная проблема проверялась измерением или браузерным тестом; классификация и решения — в `CP20_BUG_REGISTER.md`.

## 1. Архитектура

- Одна IIFE в строгом режиме; данные читаются из `<script type="application/json">` (`data-books`, `data-films`, `data-songs`, `boot`). Внешних зависимостей и сетевых запросов нет (подтверждено тестом: ресурсов, кроме `file:`/`data:`/`blob:`, не загружается).
- Состояние: `state` (отметки по разделам), `history` (события с эпохой), `flags`, тема. Ключи `localStorage`: `personal-collections-clean-cp08-v1`, `…-history`, `…-theme-choice`, `…-recovery`; устаревшие ключи CP07 переносятся один раз. **Ключи и форматы в CP20 не менялись.**
- Каталоги: три сохраняемых экрана (`#catalog-books/films/songs`), клонированные из исходной разметки; идентификаторы переименовываются с префиксом раздела, ссылки — через `data-ref` и карты `panelRefs`/`cardRefs` (без повторных `querySelector`). Карточки строятся пакетами по 24 при прокрутке.
- Модальные экраны: статистика, история, настройки; навигация через `history.pushState/replaceState`, закрытие — через `history.back()`.
- Свайпы: каталог — двигатель v11 (document-level `touch*`, capture); статистика/история — отдельные обработчики на `.sheet-body` (в CP20 переработаны).

Оценка: архитектура для однофайлового приложения разумна, связность функций высокая, но отрисовка статистики и истории была связана с глобальным состоянием, что мешало плавному свайпу — разделено (M-05).

## 3. CSS

51 КБ, ~600 правил, 17 последовательных слоёв (база, v3, v6–v17, CP07, CP08, CP19). 60 `!important`. Селекторы `.tab`, `.more-panel` определены по 6 раз; `body`, `.nav`, `.tabs`, `.art`, `.item`, `.story-short`, `.story-long` — по 5.

Перекрытые/неработающие правила (оставлены, D-03):
- `html.theme-ready{transition:--bg …}` (v6) полностью перекрыт `html.theme-ready{transition:none!important}` (v7); регистрации `@property --bg…--nav-bg` нужны только этой перекрытой анимации.
- `html.theme-ready .stat,.item,.progressbox,.nav,.btn,.mark,.art{transition-property:…}` (v6) перекрыт `transition-property:none!important` (v7) для всех, кроме `.story-toggle`, `.more-panel`, `.tab-glider`.
- `#catalog{…}` (строки 77, 102) действует только до запуска сценария (затем id становится `catalog-books`).
- `.tab[aria-selected=true]{background:var(--faint)…}` (база) перекрыт `background:transparent!important` (v6/v13) — выделение делает `.tab-glider`.
- Медиазапросы `prefers-reduced-motion` повторяются в 9 местах; противоречий не найдено.

Анимации и производительность отрисовки: свайпы и меню анимируют только `transform`/`opacity`; перекраска каждого кадра (~4 мс при 4×) — от цветов «капсулы» вкладок через custom properties, допустимо. Светлая/тёмная темы: все новые правила CP20 используют существующие переменные (`--accent`, `--panel`, `--text`), контраст проверен автоматически (раздел 3 отчёта о тестировании).
