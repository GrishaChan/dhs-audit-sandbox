# CP20 — журнал изменений

Дата: 4–5 ноября 2026. Основа: CP19 UI-FIX (SHA-256 `146bf3d7…3efd`, проверена). Исходник сохранён без изменений; точный diff — `CP20_DIFF.patch` (26 участков, +271 / −68 строк, только CSS и основной сценарий).

## Результат для пользователя

1. **Свайпы в статистике и истории стали плавными.** Содержимое движется за пальцем, соседняя категория въезжает с края; при отпускании движение продолжается с той же скоростью, недостаточный жест плавно возвращается, у крайних вкладок — лёгкая «резинка» без перехода. Новое касание может подхватить незавершённое движение. Вертикальная прокрутка нативная.
2. **Активные переключатели статистики заметны на всех трёх уровнях**: категория (золотистый/розовый/зелёный, как в CP19), «Моя активность / Коллекция» и «День / Месяц / Год / Всё время» — заливка и рамка 2 px в цвете текущей категории, читаемый текст. Тот же стиль у выбора темы в настройках. Размеры и компоновка не изменены.
3. **Свайп каталогов**: убрана пауза в начале жеста (каталоги заранее разложены) и лишний пересчёт стилей в конце.
4. **Навигация**: системная кнопка «Назад» в карточке истории записи возвращает к списку; отменённый свайп каталога больше не переключает каталог при открытии меню; «Сегодня» в статистике не устаревает, если вкладка оставалась открытой после полуночи.
5. **Производительность при длинной истории**: статистика с 10 000 событиями строится за десятки миллисекунд вместо 0,6–1,6 с (форматтеры дат создаются один раз); действие больше не перечитывает и не проверяет всю историю, если её не меняла другая вкладка.

## Неизменно

- Все четыре JSON-блока (`data-books`, `data-films`, `data-songs`, `boot`) и встроенные иконки (`ART_IMG`, `MINI`) **побайтно совпадают с CP19**: 496 книг, 500 фильмов, 500 песен, 201 / 0 / 0 отметок скачивания, пустая история, чистый прогресс.
- Ключи и форматы `localStorage`, миграция CP08, статусы и их взаимоисключение, расчёты статистики, импорт/экспорт, сохранение каталога с отметками.
- Сторонние библиотеки не добавлены, файл остаётся единым и работает через `file://` без интернета.

Редакторский аудит фильмов №251–300 не проводился.
